# The Polibrand Agency

The leading political branding partner for political leaders across Africa. This platform provides strategic branding, campaign communication frameworks, and leadership positioning.

## ✨ Features
- **Professional Branding**: High-end landing page with dynamic Hero sections.
- **Brand Management**: Admin dashboard for real-time colors, typography, and logo customization.
- **Responsive & Native Feel**: Fully optimized for mobile with touch-friendly layouts and professional transitions.
- **Global Settings**: Instant synchronization between admin settings and public-facing pages.

## 🚀 Live Deployment
- **Production URL**: [https://thepolibrandagency-d4263.web.app](https://thepolibrandagency-d4263.web.app)
- **Deployment Platform**: Firebase Hosting / Firebase App Hosting
- **Version Control**: GitHub

## 🛠️ Tech Stack
- **Framework**: [Next.js](https://nextjs.org) (App Router)
- **Backend Platform**: Firebase Admin SDK, Firestore, Firebase Storage, Firebase Auth ID tokens
- **Styling**: Vanilla CSS with Global Design Tokens (CSS Variables)
- **State Management**: React Context (SettingsProvider)
- **Animations**: CSS Keyframes & Framer Motion

## 📦 Getting Started

First, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.
